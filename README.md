# Сервис форм отклика

Менеджер собирает форму отклика в админке и получает ссылку. Студент по ссылке заполняет форму. Менеджер смотрит ответы и видит, на каком шаге студенты бросают заполнение.

> Проект в разработке: README дополняется по мере готовности частей.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

После запуска:

- админка: http://localhost:3000/admin
- проверка, что сервер жив: http://localhost:3000/api/health

### Другой порт

Порт задаётся переменной окружения `PORT` (по умолчанию 3000).

```bash
# macOS / Linux
PORT=4000 npm start
```

```powershell
# Windows PowerShell
$env:PORT=4000; npm start
```

## Структура проекта

```
server.js        точка входа: читает настройки и запускает HTTP-сервер
src/app.js       Express-приложение: маршруты и обработка ошибок
src/config.js    чтение настроек из переменных окружения
pages/           HTML-страницы
public/          статика (стили, скрипты), доступна по /static
```
